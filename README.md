# WVF12

PC 微信小程序 **强开 F12** 便携版发行页（不含源码）。

## 下载

请到 **[Releases](https://github.com/Sakura285/WVF12-/releases)** 下载：

**[WMPFDebugger-portable.zip](https://github.com/Sakura285/WVF12-/releases/latest/download/WMPFDebugger-portable.zip)**

## 使用

1. 解压 zip 到短路径（如 `D:\WMPF\`）
2. 双击 `WMPFDebugger.exe`
3. PC 微信打开小程序
4. Chrome/Edge 打开窗口打印的 DevTools 地址
5. （可选）`WMPF-MCP.exe` → http://127.0.0.1:17890/console

必须保留解压后的 `app\` 目录。含 Frida，杀软可能误报，请加白名单。

仅用于授权调试 / 安全研究。
